# Tripleten web_project_homeland

## Descrição

Landing page responsiva desenvolvida em HTML5 e CSS3, inspirada na TripleTen Art Gallery. O projeto apresenta uma estrutura moderna com destaque para título, imagem, texto informativo e rodapé, adaptando-se aos diferentes tamanhos de tela (desktop, tablet e mobile).

## Tecnologias e técnicas utilizadas

- HTML5
- CSS3
- Metodologia BEM
- Flexbox
- Media Queries
